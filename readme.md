# Urban Wear — TCC

Projeto feito somente com HTML, CSS e JavaScript.

## Como executar
1. Extraia a pasta.
2. Abra a pasta `tcc` no VS Code.
3. Abra `index.html` com o Live Server.

## Estrutura
- `index.html` — página inicial
- `paginas/` — páginas internas
- `css/style.css` — estilos
- `js/app.js` — interações
- `js/produtos.js` — catálogo
- `img/` — imagens dos produtos e do modelo

As imagens do catálogo são referenciadas pelo nome do arquivo, e o JavaScript ajusta automaticamente o caminho quando a página está dentro de `paginas/`.
